What this estimate includes
  • Estimated reviewer time for the selected scope, using the rates above. The range is a planning guide.

  • Fixing issues, retesting, runtime testing and scan or model execution time are excluded.
  • Excluded or unsupported files may need additional review. Targeted review covers files linked to scan evidence and may miss other relevant code.
  • Scan matches need validation. A suppressed finding does not prove the code is safe.
